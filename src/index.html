Interaction Lab

Le code devient une expérience.

Un petit aperçu de la façon dont j’utilise JavaScript pour créer des interfaces vivantes, structurées et réactives.

Event delegation

Un seul écouteur sur le conteneur gère plusieurs actions. Clique sur une interaction.

event.target → choisissez une interaction
JavaScript ready 
const demo = document.querySelector('.demo-buttons');

demo.addEventListener('click', event => {
  const button = event.target.closest('button');
  if (!button) return;

  // Une logique, plusieurs interactions.
  handleInteraction(button.dataset.demo);
});
Pattern utile pour les menus, filtres, listes dynamiques et interfaces complexes — avec moins de listeners et une logique plus facile à maintenir.
